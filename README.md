## 1. Game Title

Free-Fire

Free-Fire is a browser-based Battle Royale survival game inspired by Free Fire. The game will be designed using HTML, CSS, and JavaScript.

## 2. Main Objective

The main objective is to become the last survivor in a match with 20 participants: one human player and 19 computer-controlled enemies (bots).

The player must explore the map, find weapons and supplies, eliminate opponents, and survive until the end of the match.

## 3. Player Controls

| Key or control    | Action |
| ----------------- | ------ |
| W, A, S, D        | Move   |
| Shift             | Run    |
| Ctrl              | Crouch |
| Spacebar          | Jump   |
| Mouse             | Aim    |
| Left mouse button | Shoot  |
| R                 | Reload |

## 4. Gameplay

The game will use a 2D perspective designed to simulate a third-person Battle Royale experience.

The main gameplay features will include:

- A medium-sized map inspired by Bermuda Remastered.
- Locations with familiar names such as Peak, Factory, Clock Tower, Observatory, and Riverside.
- 20 participants: one player and 19 computer-controlled bots.
- Two selectable characters: one female and one male, both with backpacks.
- Two initial weapons:
  - MP40 for close-range combat.
  - SCAR for long-range combat.
- Weapons and supplies will appear randomly around the map.
- Players can collect health kits and ammunition.
- A shrinking safe zone that damages players outside its boundaries.
- Bots that can move, follow, and attack the player.
- Background music and sound effects.
- A loading screen, main menu, and results screen.

## 5. Scoring System

Players will earn points through:

- 10 points for each enemy eliminated.
- Additional points for every minute survived.
- A bonus for winning the match.

The game will also save personal records, including highest score, most eliminations, and total victories, using the browser's local storage.

## 6. Winning and Losing Rules

Winning:

- The player must become the last survivor.
- All opponents must be eliminated or defeated.

Losing:

- The player loses when their health reaches zero.
- After being eliminated, the player can watch the remaining bots.
- The player can choose to return to the main menu.

At the end of each match, a results screen will display the player's final position, eliminations, survival time, score, and personal records.

## 7. First Version

The first version of Free-Fire will include:

1. Main menu with the game title and a Play button.
2. Character selection between one male and one female character.
3. Medium-sized Bermuda-inspired map.
4. 19 computer-controlled enemies.
5. Character movement, aiming, and shooting.
6. MP40 and SCAR weapons.
7. Health kits and ammunition.
8. Shrinking safe zone.
9. Scoring and personal records.
10. Victory, defeat, and results screens.

Technical Requirements:

The game will be developed using only HTML, CSS, and JavaScript. It will be published on GitHub Pages as a static website.

It will not require a backend, database, login system, payment service, Python server, or secret API keys.

Advanced features such as vehicles, additional weapons, character skins, and real multiplayer will be considered for future updates.
